# תמונת נושא לדף הפייסבוק העסקי

הקובץ המוכן: `facebook-cover-1640x624.png` (פי שניים מתצוגת המחשב 820 על 312, הטקסט בתוך האזור הבטוח לטלפון).

לבנות מחדש, או להחליף את הרקע המאויר בתצלום אמיתי מההרצאה:

```
python3 gen_banner.py                # רקע מאויר
python3 gen_banner.py /path/photo.jpg # תצלום אמיתי כרקע, אותם טקסטים ואותם מיקומים
NODE_PATH="$(npm root -g)" node render.js facebook-cover-1640x624.png
```

## הגרסה עם הקהל האמיתי

`facebook-cover-audience-1640x624.png` היא הגרסה שבה הקהל מההרצאה (פריים מהסרטון "גברים או נשים מי מאושר יותר") משמש כרקע. הרקע החתוך והמוגדל שמור ב-`bg-audience-1640x624.png`, והפריים המקורי כפי שנחתך מצילום המסך ב-`audience-frame-source.png`. הפריים הגיע מצילום מסך של יוטיוב, ולכן הוא רך. הגדלה פי 2 עם הסקיל של הגדלת התמונות במק תחדד אותו, ואז מריצים שוב:

```
python3 gen_banner.py bg-audience-1640x624.png
```
