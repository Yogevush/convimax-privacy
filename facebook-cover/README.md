# תמונת נושא לדף הפייסבוק העסקי

הקובץ המוכן: `facebook-cover-1640x624.png` (פי שניים מתצוגת המחשב 820 על 312, הטקסט בתוך האזור הבטוח לטלפון).

לבנות מחדש, או להחליף את הרקע המאויר בתצלום אמיתי מההרצאה:

```
python3 gen_banner.py                # רקע מאויר
python3 gen_banner.py /path/photo.jpg # תצלום אמיתי כרקע, אותם טקסטים ואותם מיקומים
NODE_PATH="$(npm root -g)" node render.js facebook-cover-1640x624.png
```
