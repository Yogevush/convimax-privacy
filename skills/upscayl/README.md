# סקיל הגדלת תמונות לקלוד במק

הסקיל הזה מחבר את קלוד במחשב המק למנוע ההגדלה המקומי של התוכנה

Upscayl

אחרי ההתקנה אפשר להגיד לקלוד במק "תגדיל את כל התמונות בתיקייה הזו פי 4" והוא מריץ הכל לבד, במחשב, בלי להעלות שום דבר לאינטרנט. הקבצים המקוריים לא נפגעים. התוצאות נשמרות בתיקייה חדשה בשם

upscaled

ליד התמונות המקוריות.

## התקנה במק (פעם אחת)

תנאי מקדים: התוכנה מותקנת במק. אם לא, ההתקנה בפקודה אחת:

```
brew install --cask upscayl
```

או הורדה מהאתר של התוכנה וגרירה לתיקיית האפליקציות.

התקנת הסקיל, שורה אחת בטרמינל או בקלוד קוד במק:

```
curl -fsSL https://raw.githubusercontent.com/yogevush/convimax-privacy/main/skills/upscayl/install.sh | bash
```

הפקודה מעתיקה את הסקיל לתיקיית הסקילים האישית של קלוד קוד ובודקת שהתוכנה מותקנת.

## מה יש כאן

- `SKILL.md` ההנחיות שקלוד קורא כשהוא מפעיל את הסקיל.
- `scripts/upscale.sh` הסקריפט שמריץ את המנוע על קובץ או על תיקייה שלמה.
- `install.sh` סקריפט ההתקנה.

## הערה חשובה לשימוש מסחרי

שלושה מתוך שבעת הדגמים בתוכנה מסומנים בתוכנה עצמה כמותרים לשימוש לא מסחרי בלבד. הסקיל יודע את זה ומשתמש כברירת מחדל בדגם שמותר לשימוש מסחרי. לתמונות מוצר, דפי מכירה ופרסום אין לבחור בדגמים

remacri, ultramix-balanced, ultrasharp
